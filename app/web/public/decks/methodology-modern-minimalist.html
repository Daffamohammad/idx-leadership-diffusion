Slide 04 — Methodology rules

How each signal is computed

Leadership (20D excess vs IHSG)

  • LEADING — excess ≥ +5pp
  • IMPROVING — excess between −5pp and +5pp
  • WEAKENING — excess drops from LEADING into IMPROVING
  • LAGGING — excess ≤ −5pp

Diffusion (20D breadth delta)

  • BROADENING — breadth delta > +5pp
  • STABLE — |breadth delta| ≤ 5pp
  • NARROWING — breadth delta < −5pp
  • UNCONFIRMED — no comparable prior snapshot

Concentration (top-3 share)

  • Computed on persisted absolute contributions
  • LOW < 45%; ELEVATED 45–65%; HIGH ≥ 65%
  • Reported as percent share of absolute contribution

Foreign-flow sample gate

  • market_days ≥ 5 · obs ≥ 30 · mapped ≥ 80%
  • Coverage gate currently fails on mapped-pct (75%)
  • signal_eligible = false → SAMPLE ONLY label

Slide 08 — Release gates

Honest gates, not gate-keeping

  • READY only when coverage_pct ≥ 60% and methodology_version matches prior.
  • READY_WITH_GAPS surfaced whenever a denominator is below the 60% gate but ≥ 30%.
  • DATA_GAP when no numeric observation exists (fundamentals today).
  • UNCONFIRMED when trajectory requires a comparable prior that does not exist.
  • SAMPLE_ONLY on every foreign-flow surface so users know it is not market-wide.
  • CONTEXT_ONLY on every research-event badge; events never score signals.
